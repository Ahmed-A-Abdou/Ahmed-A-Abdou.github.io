Unity 6 C# ScriptableObject Modules Composition

Shell Behaviours

The System
A shell flies; everything else it does is a module. Its behaviour is a list of small ScriptableObject assets dropped onto it, so a new kind of round is a new combination of modules, and a new behaviour is a new module asset.
The Module Hooks
ShellModule is an abstract ScriptableObject with three optional hooks: Launch(shell), Tick(shell) and Impact(shell, point). The shell holds a List<ShellModule> and calls each hook at its moment, passing itself; on impact it finishes landing first, then calls the modules.
The Behaviours So Far
  • HE: the explosion and scorch on impact
  • Smoke trail: propellant smoke dragged out of the barrel, gone within half a second
  • Rifling spin: the spin the barrel's grooves give the shell, at a rate a camera can read
  • Report leak: tells the air defence a shell got through
Next on the list: flare, incendiary and a laser-guided round, each a new module.
Shared and Stateless
One module asset serves every shell of that type, so a module may only hold authored settings; anything about one particular shell is handed in. I checked the rule with a scenario before writing code: two shells and one module that saved the impact point in a field, and the first shell explodes at the second one's landing point. The same rule caught a real bug in the first HE module, which stored the spawned explosion in its prefab field and broke the next shot.
The Flight
The shell flies by script, not a Rigidbody, so it lands exactly where fire control predicts. Each step uses the exact constant-gravity update, position += v·dt + ½·g·dt² then v += g·dt; the obvious order (velocity first) falls slightly too far every step and missed by about 2 m over a 20-second lob.
Becoming a Target
An Interceptable add-on component makes a shell a target for the air defence through the same contracts the drones use, and the report-leak module announces when one lands. That's how the shells plugged into the C-RAM without the C-RAM changing; the story and the numbers are on The Interception.
Where It Lives
Today the modules live inside the artillery assembly. Moving shells and modules into their own munitions assembly, so mortars and rocket artillery can reuse them, is the next structural step.
