About Me

Unity Game Developer focused on gameplay systems, simulation and VR. I build decoupled architectures with ScriptableObjects, state machines and interfaces, where new behaviour arrives as a new asset or a small new class instead of an edit to code that already works.

Shipped work includes Cyber Ninja, a rhythm-action VR game for Meta Quest 3, and ZiRunner, a bilingual English/Arabic multiplayer training game built on Photon PUN 2. On my own I'm building MilSim, a framework of military systems (a C-RAM air defence, drone swarms and a 2A65 Msta-B howitzer) that work together without knowing about each other. Its reusable core is released as Emplacement, an open-source Unity package.

I spent 2 years as a Game Development Instructor, designing curricula and helping 30+ students ship real projects, and in October 2026 I hosted the game development session at NASA Space Apps Shebeen El-Kom, a competition I once competed in. Explaining a system in plain terms is still one of my favourite parts of the job.
